# 替代源口径审计与修正

小样本17项一致不能证明全量等价。扩大到243只股票的实际取数后，发现以下具体问题，均在最终数据验收前处理。

## 金融收入分母

锦龙股份2015年半年报的营业总收入为1,352,716,949.58元。来源是[公司半年报摘要](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=1899876&stockid=000712)。东方财富同一期`ORG_TYPE=证券`，`OPERATE_INCOME`只有12,068,927.54元，而`TOTAL_OPERATE_INCOME`与公司公告一致。前者是部分业务收入，不能作为金融报表完整净利率分母。

因此对银行、证券、保险报表使用`NETPROFIT/TOTAL_OPERATE_INCOME`；普通报表仍用`NETPROFIT/OPERATE_INCOME`。该例修正后约0.629881，与已有BaoStock值在六位小数精度吻合。这是报表口径修复，不是为了收益或一致率挑分母。

## 重组后的历史比较数据

[七喜控股原2015年三季报](https://static.cninfo.com.cn/finalpage/2015-10-23/1201714500.PDF)第3页显示，前三季度归母净利润为-2,704,864.94元，营业收入312,199,051.44元。当前东方财富2015Q3行却给出归母净利润2,488,035,743.31元，UPDATE_DATE为2016-10-31，NOTICE_DATE仍是2015-10-23。

[分众传媒2016年三季报](https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=2837980&stockid=002027)说明，反向收购下的合并比较数据使用会计购买方分众多媒体的2015年数据，母公司单体比较数据才使用原七喜控股。因而不能将当前重述值放回旧公告日，笼统标记“修订未知”不足以处理这个已证实的差异。

最终替代源主面板采用各依赖NOTICE_DATE与UPDATE_DATE的最大值作为保守可用时间，早于该时间的原报告值保持缺失。它不会恢复当时的旧版本，也不保证覆盖率；并非完整历史版本PIT。跨源数值比较仍可使用公告对齐诊断，但不得用于主面板的时间放行。

## 无效日期

两家券商002500、002673的12条资产负债表/利润表记录使用1900年公告占位值，均处于2006–2007年，早于它们原计划及所需年初权益依赖区间。原始响应保留，异常单独列出；需要进入原计划或依赖的无效日期会阻止构建，不能猜测发布日期。

## 证据版本

`20260906T132740437179Z`因日期异常停止；缓存保留。`20260906T133215115954Z`完成取数并生成公告对齐初稿，但金融收入分母和修订时序尚未修正，不是最终数据交付。该初稿独立核验还暴露全缺失列None/NaN类型问题，已统一为浮点缺失并加以核对。
