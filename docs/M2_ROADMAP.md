# M2：收束后的研究路线

依据《A股量化论文》最新一轮仓库评审讨论，当前任务是寻找相对现有技术信息的增量。外部对话中的完成百分比是主观评价，不作为验收事实。

编号以[项目上下文](PROJECT_CONTEXT.md)为准：M2.0基础设施、M2.1 Value pilot已完成；M2.3拆为季度数据与经济家族两个子项。2026-09-06同步路线，实验结果未改变。

## 已收尾与工程边界

M0冻结；M1功能验收结束，三个FORWARD仍有数据缺口及负测试超额，不因此重新扩建M1。M2首轮是基础设施v1 + 一个Value因子族试验，BP/EP/SP不是三个独立经济机制。

现有缓存、FactorEngine、SQLite、报告和验收机制继续复用。只有阻塞具体研究的问题才增加实现；暂不建设新registry、dashboard、Agent UI、微服务或通用抽象层。M3未启动。

## 顺序与退出条件

当前：M2.2地图与BP条件诊断已完成，[结果](results/m2_alpha_map/report.md)。
158项原公式中156项满足地图覆盖要求，强相关聚类得到123个技术代表。
直接用123维投影时共同样本不足，保留了[原结果](results/m2_alpha_map_v1/bp_conditional.json)。
因此补充了只在2015拟合的PCA：预定方差目标90%，最多20维；实际保留77.7%，
未达到90%目标，不能把压缩参照当作完整技术信息空间。2016投影后BP仍有正RankIC，
但这不是模型增量或独立Alpha确认。后续M2.3首批结果见下。

M2.2的线性参照只能表达部分技术信息；低相关或线性残差显著不能替代非线性模型的增量实验。每个聚类代表也不一定构成线性无关的数学基底。

## 日期用途

- 2008–2014：历史训练；2015–2016：已观察研究数据。
- 2017–2020：已消耗诊断数据，不能重新命名为新鲜样本外。
- 2021–2023：保留为qualification；2024–2025：保留为lockbox。
- 2026：是否可作forward取决于该方案此前是否看过相应数据，不自动声称未触碰。

地图批次仅读取2015–2016特征（历史滚动窗口可向前取数），在2015上无监督确定聚类和代表，冻结后在2016诊断BP。两个年份都已经用于历史研究，不能称为独立验证。2021后不取数、不读取收益。

Qualification和lockbox的日期保护已明确；完整数值门槛与执行协议仍需在M2.5结束后、取数前冻结，当前不声称协议或验收已完成。

## M3进入条件

完成Alpha158地图与代表参照、至少4个经济因子族研究、研究范围内季度PIT面板与限制审计、中性化/独立性分析、滚动LightGBM add/drop，以及qualification/lockbox协议冻结。若数据阻塞，记录真实缺口，不用增加Agent掩盖。即使门槛完成也不自动启动M3；先报告M2研究结论。

## 本轮推进结果与退出决定

M2.3a已完成2015–2016全部392只历史成分的盈利/成长季度面板，10,192个请求、9,896条有效接口记录、0异常。未完成2008–2020全研究历史，不因此宣布M2.3整体结束。[数据报告](results/m2_quarterly/report.md)。

M2.3以已有BP为Value参考，预注册Quality(+ROE)、Growth(+净利润增长)、Investment(-资产增长)三项新公式。中性化后的历史RankIC分别0.0069、-0.0015、0.0051，三项均IC_SCREEN_REJECT；四个经济家族已进入首轮研究，但没有新的FORWARD/KEEP。[结果](results/m2_family_screen/report.md)。

收束决定：关闭本批三个具体公式，不翻方向、不在相同样本调参救回；不将结果外推为整个经济家族无效。BP仍保留原FORWARD状态。下一批先明确更长的已观察研究区间、财报口径、金融行业可比性及年度稳定性检查，并预注册数量有限的补充批次；之后集中做含成本增量和滚动模型。BP优先但不独占路线。三个公式失败不能结束三个经济家族。补充批次协议尚未冻结或执行。完整历史数据与其他未完成门槛仍需满足后才可声称M2完成或进入M3。

本轮条件诊断仅覆盖M2.4的一部分：复现既有20-PC参照，未新增组合回测或滚动模型。资格和锁箱未访问。141项测试通过；具体证据见各报告。

本轮季度独立验收：956,480个日度面板值、10,192个原始响应哈希和1,581个产物哈希通过核验。[验收记录](results/m2_quarterly/independent_verification.json)，[141项回归测试](results/m2_quarterly/regression_tests.txt)。
