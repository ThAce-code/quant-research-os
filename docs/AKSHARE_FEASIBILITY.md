# AKShare历史财务替代源：小样本验证

后续状态：本文保留首次小样本判断。整批已完成，并发现需要修正的金融收入和历史重述问题；最终结论以[当前上下文](PROJECT_CONTEXT.md)、[数据口径审计](M2_ALTERNATE_SOURCE_AUDIT.md)和[完整范围数据报告](results/m2_alternate_history/report.md)为准。

2026-09-06，按用户要求测试AKShare替代路线。结论：**能够取得所需历史数据，五字段重建在小样本中吻合；尚未完成整批替代验收。** BaoStock的10001011限制仍未解除，也未确认是IP或请求频率造成的临时限制。本轮没有请求BaoStock。

本机AKShare版本1.18.94。先调用`stock_financial_analysis_indicator_em`，在HTTP参数中增加报告期2007-01-01至2020-06-30、公告日期不晚于2020-07-31的过滤，避免默认获取全部年份。铜陵有色000630返回53期，贵州茅台600519返回54期。该函数本身没有日期参数，探针明确记录了这层调整。

主要指标不能直接按名称替换：ROEJQ是加权ROE，PARENTNETPROFITTZ是归母净利润增长，原字段分别要求平均ROE、合并净利润增长。重叠数据实际存在差异。

随后使用AKShare源码中的东方财富按报告期资产负债表、利润表接口，显式指定历史日期；这是基于AKShare底层接口的受限请求，不是声称原函数自带日期参数。普通公司类型4只用于上述两只样本，没有推广到银行、保险或退市公司。两组探针合计8次HTTP请求，无自动重试。

| 原目标字段 | 对应重建口径 |
|---|---|
| roeAvg | 归母净利润 / 年初和期末归母权益的平均值 |
| npMargin | 合并净利润 / 营业收入 |
| YOYNI | 合并净利润同比字段 / 100 |
| YOYAsset | 总资产同比字段 / 100 |
| YOYEquity | 归母权益同比字段 / 100 |

检验两只股票的2007Q3、2016Q3，共20个字段值。17个有BaoStock缓存可比，**17/17差异小于0.000001，最大绝对差异4.7589e-7**，符合原缓存保留六位小数的精度。其余3个是缺少BaoStock响应的铜陵有色2007Q3成长字段，已从东方财富取得，但不能宣称完成跨源一致性验证。

证据：[逐值比较](results/m2_akshare_probe/comparison.csv)、[请求与公式](results/m2_akshare_probe/comparison_summary.json)、[主要指标接口记录](results/m2_akshare_probe/indicator_probe.json)、[源代码与本地原始响应哈希](results/m2_akshare_probe/source_and_raw_hashes.json)。本地run分别为`20260906T105247160449Z`和`20260906T105421549133Z`，原始数据未上传。

仍须解决的整批准入问题：

1. 对完整历史股票与缺失季度扩大覆盖核查，包括不同公司类型、退市和早期报表；两只股票不能证明全部覆盖。
2. 核对公告日期。主要指标与当前BaoStock缓存存在公告日期差异；必须保留接口原始日期，不能拿一个源的日期套另一个源的数值。
3. 保留修订不确定性。响应同时包含NOTICE_DATE与UPDATE_DATE，部分历史报表更新于更晚年份。报告期和公告日期过滤不等于历史版本PIT，不能据此宣称数据在原公告日就是当前数值。
4. 原口径跨表计算需要同时考虑分子、分母及年初权益的可用时间；扩大逐值校验、检查缺失和重复后，才可建立独立来源面板。不得覆盖或伪装为BaoStock缓存。

下一步是冻结替代源映射与日期规则，按原股票/季度范围进行分批取数和独立验收；不改因子方向、收益门槛或已完成模型结论，不打开2021+保护期。M2整体仍未完成，但已经有可实测的替代数据路线。

接口依据：[AKShare官方股票文档](https://akshare.akfamily.xyz/data/stock/stock.html)及本机对应版本源码。未使用第三方字段摘要作为一致性证明；数值结论来自实际响应与本地BaoStock缓存逐值比较。
