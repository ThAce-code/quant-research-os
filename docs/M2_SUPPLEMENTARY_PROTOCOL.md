# M2.3 有限补充批次

本批在查看三项已失败公式的2015–2016结果之后设计，是有记录的后续研究，不是事先不知道旧结果的独立检验。权威数值定义为 [m2_supplementary.json](../configs/factors/m2_supplementary.json)。协议冻结不等于采集、实验或验收已完成。

## 范围和预算

使用M0封存的2008–2020年7月历史CSI300每日成分。2008–2014用于历史训练准备；2015–2020年7月为已观察研究及已消耗诊断，按年度和2015–2016/2017–2020分别报告。资格期及锁箱不访问。

仅增加两个固定正方向假设：

| 候选 | 经济机制 | 计算与限制 |
|---|---|---|
| CASHFLOW_MARGIN_YTD | 现金转换质量 | 公告后可用的经营现金流/营业收入比率；保留负值，不把累计比率相加或声称TTM |
| ILLIQUIDITY_20 | 非流动性补偿 | 20个完整交易日的绝对调整后收益/原始人民币成交额均值，再log1p缩放；成本与规模暴露可能吞噬信号 |

这是在已测Value、Quality、Growth、Investment之外补充不同测量与Liquidity机制；不修改或反向重试旧ROE、净利润增长、低资产增长公式。原三项REJECT不变。

主样本固定排除J66–J69金融行业，未知行业也不归为非金融；同时公布相对全部成分的行业识别率。BP和各比较组使用相同股票范围。中性化继续复用现有方法，不能为提高覆盖而修改最小行业组大小。

## 顺序与产物

1. 生成逐股票季度请求计划及覆盖清单。现金流接口按历史成分范围加回看期采集，并补齐历史行业/规模暴露。2020Q2中在7月底前已公告的报告可以使用，之后公告的报告不得回填。三只股票的可用性探针不能替代这一步。
2. 按原始记录计算因子及年度覆盖，检查季度比率口径、同报告期比较、金融行业损耗与缺失。原始市场数据保持封存。
3. 一次执行两个五日主检验，统一BH校正；20日和预定敏感性只诊断。筛选状态不等于独立Alpha。年度完整性与数值门槛见JSON。
4. 输出含成本同样本比较；随后单独冻结滚动模型协议。BP和两个固定补充公式的数据质量通过后可进入有预算的模型比较，单因子IC弱不能被偷换为“没有任何模型信息”。

本补充批次结束后停止新增公式，保留失败结果。完整M2仍需独立性、模型增量及有条件的资格/锁箱阶段。新时期失败后不得改公式重测并冒充确认。
