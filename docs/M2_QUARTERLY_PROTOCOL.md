# M2.2–M2.3：本轮边界与预注册

本轮从3只股票的接口核验扩展至2015–2016全部历史CSI300成分。精确期间并集392只；旧Value批次的409只包括2014年12月预热范围，两者不矛盾。每日覆盖分母按当日成分计算，不使用今天的成分名单。

## 数据阶段

固定请求2013Q3至2016Q3的盈利和成长接口。早期季度用于检查初始可用报告，最后一季为2016Q3：2016年报不能在2016年末提供已公布的正式年报信号。

逐股票、逐接口按pubDate向后对齐，公告当天不可用；只有下一个实际交易日及以后可使用。较早统计期的迟到报告不能覆盖已经公布的新统计期。公告年龄超过400天、统计期年龄超过550天均不使用；最新报告缺失字段不回填旧值。记录空响应、异常日期、重复修订及字段缺失。供应商不提供完整历史版本，始终标记revision_unknown。

保存每个请求的参数、采集时间及原始响应哈希。仅小型覆盖表、协议和报告公开；完整季度事件与日面板保留本地。

## 有限经济假设

| 家族 | 主候选 | 固定方向 | 解释与局限 |
|---|---|---|---|
| Value | 已有BP | 正 | 账面价值相对价格；沿用已有结果作为参考，不重计一次新发现 |
| Quality | roeAvg | 正 | 供应商报告期ROE，非自行重建TTM；需留意累计期、负权益及金融业可比性 |
| Growth | YOYNI | 正 | 供应商净利润同比；低基数、负利润及修订可能导致失真 |
| Investment | YOYAsset | 负 | 低资产扩张假设；仅为投资强度代理，金融企业与并购等可能不可比 |

三个新主检验固定为行业和流通市值代理中性化版本。npMargin、YOYEquity仅做数据检查，不据其收益新增候选。没有方向翻转、窗口网格或测试后替换公式。

## 历史筛选门槛

主标签、可交易端点及费用口径沿用现有引擎。此轮先做5日标签IC筛选：每年覆盖至少70%、整体RankIC至少0.01、两年RankIC均正、20日块自助法单侧检验，三个新假设共同做BH校正且q<=0.10。全部通过仅为IC_SCREEN_PASS，不等于FORWARD、KEEP或可投资；其后仍需含成本同样本组合增量。

2016条件诊断沿用M2.1在2015拟合的20个主成分及联合行业/规模投影，候选与残差必须使用完全相同股票。已知仅保留77.7%代表特征方差，残差可能含遗漏的技术信息。条件结果不另设一组可供挑选的主假设，也不替代LightGBM滚动add/drop。

两个年份都属于已观察历史。此批仅完成小范围的全股票覆盖与预注册家族筛选；M2.2的全研究历史、M2.4组合增量及M2.5模型验证尚需继续。2021–2023资格期和2024–2025锁箱不取数、不计算标签。
