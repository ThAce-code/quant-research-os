# R2 事件研究：先核查当时可知的信息

用户在R1收束后授权继续，当前执行R2.0数据可行性批次。R1结果和预算保持关闭。R2尚未冻结收益假设、模型预算或保护期准入规则；本批不产生因子评价、IC或交易。

`configs/r2/event_audit.json`于采集前提交`befc46c`：2015/2016一季度预告和快报，最多48次串行请求，单页500行，每次间隔至少一秒，无失败重试；仅请求研究期报告与2020-07-31之前公告。八次请求完成四个查询，未接触BaoStock。

可接受的事件记录必须区分：报告所属期间、公开披露日期/时间、文书落款日期、原始数值、后续修正及其生效时间。不能用报告期当发布日期，不能用文书落款提前交易，不能把后来修正值回填首次披露日。预告可以早于报告期结束，不能直接套用要求`statDate <= pubDate`的季度财务转移函数。

单个最新快照不等于版本链；供应商字段名也不等于已确认口径。现有整理接口的字段裁剪见[AKShare官方源代码](https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_yjyg_em.py)。原始接口和整理接口分开核对，未把冲突字段直接当作原公告同比变化。

在完整性未知时，不把缺少预告当成零意外，不把修正公告标题必然解释成有一份旧数值，不从未来修正文书单独恢复过去可交易值。先归档原文与公布日证据，形成少量完整的首次预告—修正链，再制定系统性采集规则和覆盖验收。手选案例仅用于数据质量反证和时间对齐验收，不能据此筛选股票或统计收益。

本批报告见[事件可行性审计](results/r2_events/report.md)。数据尚未获准进入因子回测；2021–2025封存，模拟盘未启动。后续需要在新增公告语料可行后事前定义事件窗口、非事件日缺失政策、最小事件样本、基准和多重比较预算，不能为了稀疏覆盖事后降低R1门槛或称复用R1即可完成事件研究。

下一步只在已归档语料上审查数值、指标、报告期、单位和版本。年报内嵌预告须定位对应页/段，定性预告上下界为null，源数值矛盾隔离，全文与摘要按事件去重，日线可用日严格晚于来源公告日。索引时间戳不自动证明历史时分精度；取得时间不是历史公开时间。

标题或同日匹配仅为候选文书发现，不能据此将年度快报或业绩说明会当作当季预告。回溯发现的旧公告也不能未经可用性审查就视为当时完整可得。本批不宣称全量历史版本已齐、没有新增因子准入；收益假设和预算仍待在实际可用数据覆盖基础上冻结。
