# 行业过渡文本修正记录

在完整数据审计中发现，2007–2012原始快照除了“金融保险业”外，还有42条根类别为“金融业”的过渡文本。它们没有现代J66–J69代码，最初的LEGACY金融识别遗漏了这个同义根类别。原始文字可读，问题是分类排除实现，不是需要猜测的历史行业映射。

修正仅将两个明确的金融根类别都排除：`金融保险业`、`金融业`。所有其他完整旧文本分组不合并，不用未来行业回填，2015年后的分数仍必须与原补充实验完全一致。原始快照的updateDate晚于请求快照日期的记录为0。

首个模型输入run `20260906T090208399969Z`、滚动run `20260906T090722431779Z`及其保护期退出记录 `20260906T092315233266Z`被保留，但不能作为最终模型结论。修正后复用哈希一致的Alpha158和标签，再执行同一冻结协议：相同候选、窗口、参数、seed、费用、阈值与统计预算。重跑是实现缺陷修复，不是按旧收益搜索或调整门槛。有效模型结果以修正后run为准。

2016条件诊断的输入不受该训练期修正影响；它仍是明确披露时间顺序的后验诊断，不能改变任何筛选结论。

有效输入为`20260906T092519215478Z`，有效滚动模型为`20260906T092732142566Z`，对应保护期无准入记录为`20260906T093550340089Z`。修正后的三个主比较均为NO_GO；独立预测重放通过。详见[当前上下文](PROJECT_CONTEXT.md)和[模型报告](results/m2_rolling/report.md)。
