# M2.4–M2.7 固定增量与退出协议

权威数值定义见[配置](../configs/factors/m2_rolling.json)。冻结时间为历史滚动模型首次运行之前；已有两项补充单因子结果均失败，不能把此设计称为完全未经观察的假设。新模型研究不改变原筛选状态。

模型比较保留全部158个技术特征，使用固定M0 LightGBM参数和seed 42，2015–2020逐年扩展训练、前一年验证、两个交易日标签清洗。四种输入为BASE、BASE+BP、BASE+现金流、BASE+两者，共24次固定拟合，无搜索。现金流尽管单因子偏弱，研究期数据覆盖通过，按补充协议允许在固定预算内检验非线性增量；非流动性已被覆盖门槛排除，不另改定义。

所有模型使用同一天完全相同的非金融历史成分和可用分数行。原始Alpha158缺失保留给模型处理，无全历史拟合的填补或缩放。标签沿用M0的一日未来持有区间，按相同股票集合在训练日截面排名；这不是重新测五日单因子门槛，也不直接与M0原全股票收益相减。训练至少100,000行、验证至少20,000行，否则记录数据失败而不是缩短历史。

三个add-versus-base为主比较，RankIC增量统一BH；ADD_BOTH与单项的差完成drop诊断。预测按年度拼接后进行连续Top50/drop5含成本回测，不在每年重置资金。固定75%技术模型预测排名+25%候选排名的两个配对组合用于M2.4诊断，不用于挑选胜者。原有相关/PCA结果保持为不完整线性诊断，全特征模型比较才检验完整技术参照下的增量。

历史GO需要同时满足RankIC增量0.002、BH q≤0.1、含成本年化增量2个百分点、20日block bootstrap的收益增量区间下界大于0，且2015–2019至少4个完整年增量为正。2020仅部分年。候选选择和并列规则均写入配置。

2021–2023只允许一个历史GO胜者进入资格验证；2024–2025只允许资格通过者进入一次锁箱。两个阶段的数值门槛已预先列入配置，不能看过结果后修改。没有上游合格候选时，下游交付物应为有上游证据和未访问核验的NOT_OPENED记录，不能谎称测试已运行、通过或找到Alpha，也不能为了把进度表填满而消耗锁箱。完整研究退出必须保留这一决策链，数据和M2.0–M2.5仍须按原范围完成。
