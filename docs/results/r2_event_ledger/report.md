## 修正了一个会污染金额的提取错误

旧 `annual_q1_fields` 先删除全部空白，导致金额上界与下一行年份连接。海康威视的 `109,861.31` 万元被读为 `109,861.312014` 万元；比亚迪2015Q1的 `15,000` 万元被读为 `150002014` 万元。后者是数量级错误，不能以舍入误差处理。

现在保留数字单元格边界，并用十进制金额换算。20份旧模板记录已逐项列明更正值；这些旧记录一直标为待审核，未送入因子回测。历史报告及哈希不改写，新证据以本批[更正表](extraction_corrections.json)为准。旧回归测试只有无后续行的孤立模板，漏掉了这一真实表格边界；新增测试覆盖整数、小数及负数上界后紧接下一行年份的情况。修正提交 `c481dc0`。

## 保留的源质量问题

- 麦迪原件金额与其同比存在算术不一致；修正引用公告号2015-017，而已找到原件编号为2015-014。保留两条转录事实，但隔离链，不凭日期相同放行。
- 奥飞002292的年报摘要正文说同比下降50%以上，表格却为-15%至+15%；PDF视觉检查确认源内矛盾。保留表格数值并隔离，未自行选择更“合理”的表述。
- 雪迪龙明确此前未披露一季预告，没有构造零值前身。桑德只有定性判断，数值上下界保持null。
- 两份带“已取消”标记的年报文书取消时间未知，均隔离。已转录的金风摘要也未进入事件表；不能把今天可见的取消状态当作精确历史时间。
- 徐工及中航动力的归母净利润金额与此前原文诊断一致；涉及重述基数、合并范围或以前年度亏损分母的同比，保留为单独的派生字段。没有把派生百分比伪装成原文印出的同比，也没有混用两个供应商的基数。

原文证据见[事件表](events.json)、[文书处置清单](document_dispositions.json)、[版本引用](version_links.json)。本批20份显式模板采用归档页文本核对，另对比亚迪2015Q1、奥飞2016Q1、上海莱士修正及徐工2015Q1渲染PDF并检查表格布局；其他既有手工案例保留各自原来的审查方法。本批并未宣称逐页审查全部5,458页。
